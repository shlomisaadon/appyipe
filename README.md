# Appyipe

A multi-page HTML and CSS website presenting a customer-service and chatbot concept, with original commits from March 2021.

## Pages

- [Home](index.html)
- [Services](service.html)
- [FAQ](faq.html)
- [Team](team.html)
- [Contact](contactUs.html)

The project includes page layouts, shared navigation, illustrations, and animated images. Some page sections contain the original placeholder copy.

## View locally

```sh
python3 -m http.server 8080
```

Open `http://localhost:8080`.

## Project history

[Original March 2021 commits](https://github.com/shlomisaadon/appyipe/commits/main/?since=2021-03-01&until=2021-03-31).

The repository documents early work on multi-page layouts and CSS. Current browser behavior has not been revalidated during the November 2026 documentation update.
